# Raina Shakir - Portfolio

A free, responsive student portfolio for Raina Shakir, BS Electrical Engineering student at PIEAS.

## Files
- `index.html` - portfolio content
- `style.css` - design and responsive layout
- `script.js` - mobile navigation and current year

## Free deployment with GitHub Pages

1. Create a GitHub repository named `rainashakir-ee.github.io` (or use any repository and enable Pages).
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`.
5. Save and wait for GitHub to publish the site.

Before publishing, update any project links and add your actual project images/repositories.
